# Welcome to ProMedic+ 🚀

Hello, Developer! This project showcases an AI-driven healthcare assistant powered by Retrieval-Augmented Generation (RAG). It is designed to provide personalized, context-aware health information in English only.

## Key Features 🚀
- **English-only Support**: Handles queries and responses in English.
- **Prescription OCR**: Scans and processes both handwritten and printed prescriptions.
- **Health Information**: Provides tailored responses to health and medication-related queries.
- **Pharmacy Locator**: Find nearby pharmacies using real-time geolocation and mapping.
